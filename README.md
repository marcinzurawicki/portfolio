# Portfolio — Marcin Żurawicki

Statyczne portfolio: otwórz plik index.html w przeglądarce. Folder assets zawiera grafiki potrzebne do działania strony.

## Publikacja na GitHub Pages
1. Utwórz repozytorium na GitHubie.
2. Wgraj do głównego katalogu repozytorium pliki index.html, style.css, script.js oraz cały folder assets wraz z zawartością.
3. W ustawieniach repozytorium otwórz Pages, wybierz wdrożenie z gałęzi main i katalog / (root), a następnie zapisz ustawienia.
4. GitHub poda adres strony po jej opublikowaniu.

Projekty są koncepcyjne; wybrane wizualizacje powstały z użyciem AI, co opisano na stronie. Sprawdź dane kontaktowe i adres LinkedIn przed publikacją. Czcionki Google wymagają połączenia z internetem; dostępne są czcionki zastępcze.
